# Learning and Environment Paths

This file connects Prompt #11 ideas, repositories, and products to learning paths and environment paths.

## Purpose

Every repo or product should have a clear path for learning, review, and improvement.

## Path Types

- repo learning path
- product learning path
- service learning path
- platform learning path
- documentation path
- review path
- diagnostic path
- sandbox path

## Path Record

| Field | Notes |
|---|---|
| Name | Path name |
| Related repo | Where it belongs |
| Audience | Who it helps |
| Current status | planned, active, paused, or complete |
| Next action | The next useful step |

## Best Practice

Use a path when an idea is too broad and needs to become a sequence of small steps.

## Principle

Prompt #11 grows stronger when broad ideas become clear paths with visible next actions.
