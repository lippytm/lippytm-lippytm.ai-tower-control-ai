# Idea to Asset Pipeline

This pipeline turns ideas into usable Prompt #11 assets.

## Flow

```text
Idea -> Review -> Brief -> Prototype -> Asset -> Catalog -> Improvement
```

## Step 1: Idea

Capture the idea in plain language.

Required:

- title
- purpose
- audience
- lane
- next action

## Step 2: Review

Use `portfolio/UNIVERSAL_REVIEW_MATRIX.md`.

Decide whether to:

- document
- prototype
- package
- pause
- split into smaller tasks

## Step 3: Brief

Create a short brief:

- what it is
- who it helps
- what it produces
- where it belongs
- why it matters

## Step 4: Prototype

Create the smallest useful version:

- checklist
- guide
- prompt pack outline
- repo template
- workflow draft
- dashboard section
- service brief
- product brief

## Step 5: Asset

Convert the prototype into one asset type:

- repo asset
- product asset
- service asset
- platform asset
- learning asset
- creative asset
- operations asset

## Step 6: Catalog

Add the asset to a catalog or dashboard.

## Step 7: Improvement

Improve from evidence:

- user questions
- repo issues
- review notes
- usage data
- missing docs
- repeated friction

## Principle

An idea becomes valuable when it becomes a clear, reviewable, reusable asset.
