# Universal Review Matrix

This matrix helps review ideas, repositories, products, services, platforms, Prompt #11 Engines, and AI Swarms before expanding them.

## Purpose

Use this matrix to decide whether an idea should be documented, prototyped, packaged, improved, paused, or connected to another system.

## Review Areas

| Area | Score | Question |
|---|---:|---|
| Purpose clarity | 0-5 | Is the purpose clear? |
| Audience clarity | 0-5 | Who is this for? |
| Technical fit | 0-5 | Does it fit a known repo, stack, or environment? |
| Value created | 0-5 | What useful value does it create? |
| Reuse value | 0-5 | Can it become a template, checklist, guide, workflow, or product? |
| Documentation readiness | 0-5 | Can it be explained clearly? |
| Review readiness | 0-5 | Can it be reviewed in a small step? |
| Risk clarity | 0-5 | Are the risks and limits visible? |
| Ecosystem fit | 0-5 | Does it connect to Prompt #11, repo fleet, products, services, or platforms? |
| Next action clarity | 0-5 | Is the next step obvious? |

## Score Guide

| Score | Recommendation |
|---:|---|
| 0-15 | Park or redefine |
| 16-25 | Document first |
| 26-35 | Prototype small |
| 36-45 | High-priority candidate |
| 46-50 | Flagship candidate |

## Required Output

Every review should end with one of these actions:

- document
- prototype
- package
- improve
- connect to repo
- add to catalog
- pause
- split into smaller tasks

## Principle

Prompt #11 improves ideas by making purpose, value, risk, and next action visible.
