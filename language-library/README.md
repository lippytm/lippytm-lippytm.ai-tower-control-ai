# Prompt #11 Language Library

The Language Library is the catalog for programming languages, blockchain languages, database languages, configuration formats, and documentation formats used across the Prompt #11 workspace.

## Purpose

The library helps each repo define:

- primary language
- secondary languages
- runtime needs
- package manager needs
- validation approach
- documentation approach
- common issue patterns
- next action

## Catalog Sections

```text
language-library/README.md

```

## Repo Language Record

```yaml
repo_language_record:
  repo: lippytm/example-repo
  primary_language: unknown
  secondary_languages: []
  runtime_status: unknown
  validation_status: unknown
  docs_status: unknown
  next_action: identify language stack
```

## Principle

Every repo becomes easier to fix when its language stack, runtime needs, and validation path are documented.
