# Swarm Idea to Prototype Pipeline

This pipeline turns a raw AI swarm idea into a small reviewable prototype.

## Pipeline

```text
Idea -> Brief -> Spec -> Prototype -> Review -> Next Action.
```

## 1. Idea

Capture:

- title
- problem or opportunity
- target user
- lane
- expected value
- first next action

## 2. Brief

Create a short concept brief:

- what it is
- who it helps
- what it produces
- what repo or platform it belongs to
- why it matters

## 3. Spec

Define:

- swarm name
- participating roles
- allowed work
- restricted work
- quality checks
- owner decision points

## 4. Prototype

Build the smallest useful artifact:

- markdown doc
- issue template
- workflow template
- dashboard entry
- prompt pack outline
- bot flow outline
- landing page outline
- README section

## 5. Review

Check:

- purpose is clear
- lane is clear
- risk level is clear
- validation is possible
- next action is clear

## 6. Next Action

Choose one:

- improve the spec
- open a PR
- create a product brief
- add to fleet registry
- assign QA review
- pause or park the idea

## Principle

Every swarm starts small enough to understand, review, and improve.
