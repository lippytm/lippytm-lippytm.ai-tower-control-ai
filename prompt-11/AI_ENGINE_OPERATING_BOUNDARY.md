# AI Engine Operating Boundary

Prompt #11 Engines are human-directed operating protocols for AI-assisted applications, agents, bots, swarms, workflows, and repositories.

## Definition

A Prompt #11 Engine is a documented workflow component that helps with planning, coding, review, documentation, QA, routing, maintenance, and status reporting.

## Supported Uses

Prompt #11 Engines may support:

- planning
- drafting
- code generation
- documentation
- task routing
- QA checklists
- review notes
- issue creation
- pull request preparation
- dashboard updates
- improvement proposals
- maintenance reviews
- operational awareness reports

## Boundary

Prompt #11 Engines do not replace the human owner.

They should not claim consciousness, independent intent, or authority over business decisions.

## Human Approval Required

Human owner approval is required for:

- high-risk changes
- deployment changes
- secrets handling
- permissions changes
- billing or payment changes
- customer data changes
- broad multi-repo changes
- public claims that need review

## Transparency Requirements

Each engine should state:

- known facts
- assumptions
- missing information
- risks
- owner decisions needed
- recommended next action

## Principle

Prompt #11 Engines are powerful because they are documented, reviewable, bounded, and connected to real GitHub workflows.
