# Prompt #11 Quality Scorecard

This scorecard helps review repositories, products, services, projects, platforms, and AI-assisted work.

## Score Areas

```yaml
quality_scorecard:
  purpose_clarity: 0-5
  owner_clarity: 0-5
  user_value: 0-5
  documentation_quality: 0-5
  review_readiness: 0-5
  validation_plan: 0-5
  reuse_value: 0-5
  next_action_clarity: 0-5
```

## Review Questions

1. Is the purpose clear?
2. Is the owner clear?
3. Is the user or audience clear?
4. Is the documentation useful?
5. Is the work small enough to review?
6. Is there a validation plan?
7. Can the output be reused?
8. Is the next action clear?

## Score Meaning

```yaml
score_meaning:
  0-10: unclear
  11-20: needs_work
  21-30: usable
  31-40: strong
```

## Best Practice

Use this scorecard before expanding an idea, product, service, repo, or platform.

## Principle

Prompt #11 improves by making quality visible and actionable.
