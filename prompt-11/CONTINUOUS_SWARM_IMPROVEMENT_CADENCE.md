# Continuous Swarm Improvement Cadence

This cadence keeps Prompt #11 AI Swarms improving over time.

## Daily Micro-Cycle

Use when working actively.

```text
Review -> Pick one useful task -> Build or document -> Validate -> Update status.
```

Daily questions:

1. What is the smallest useful thing to improve today?
2. What repo, product, service, or platform benefits most?
3. What is blocked?
4. What can become a GitHub issue or PR?
5. What can become revenue or reduce friction?

## Weekly Swarm Review

Use once per week.

```text
Review fleet -> identify blockers -> select top improvements -> create issues or PRs.
```

Weekly questions:

1. Which swarms moved forward?
2. Which swarms are blocked?
3. Which repo needs the node kit next?
4. Which product or service is closest to launch?
5. Which workflow failed or needs review?
6. Which idea should be parked?
7. Which idea should be packaged?
8. What should Claude Code implement next?
9. What should ChatGPT design or review next?
10. What should Slack commands route next?

## Monthly Productization Review

Use once per month.

```text
Find reusable outputs -> package them -> update offer and delivery systems.
```

Monthly questions:

1. What became reusable this month?
2. What can become a prompt pack?
3. What can become a setup service?
4. What can become a dashboard or template?
5. What can become a lead magnet?
6. What should be added to the product catalog?
7. What should be added to the service catalog?

## Quarterly Portfolio Review

Use once per quarter.

```text
Review all lanes -> scale what works -> simplify what is unclear -> choose flagship builds.
```

Quarterly questions:

1. Which platforms matter most?
2. Which repos should be prioritized?
3. Which products or services show the most promise?
4. Which creative or educational lanes are gaining clarity?
5. Which tools are worth keeping?
6. Which tools are creating clutter?
7. What should become the next flagship system?

## Annual Evolution Review

Use once per year.

```text
Review portfolio -> preserve lessons -> set next evolution direction.
```

Annual questions:

1. What did the Business of Businesses become this year?
2. What systems produced value?
3. What should be retired or archived?
4. What should be expanded?
5. What principles should be preserved?
6. What new engine layer is needed?

## Always-On Improvement Rule

Every cycle should produce at least one of:

- issue
- PR
- document update
- dashboard update
- product improvement
- service improvement
- maintenance review
- next action

## Principle

Forever improvement is practical when it is broken into small cycles that create durable records.
