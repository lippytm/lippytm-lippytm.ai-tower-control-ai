# Crypto Ecosystem AI Oracle and AI-DNF Integration

Both projects are registered in the ChatGPT Business Control Tower even before dedicated repositories exist.

## Universal workflow

1. Gemini or Claude creates research, code, plans, or content.
2. The work is exported as a Cross-AI Handoff record.
3. ChatGPT Business identifies the project and preserves the source provider, model, sources, claims, and requested action.
4. Available providers may independently review the material.
5. Evidence and disagreements remain visible.
6. GitHub publishing opens a draft pull request.
7. A person approves high-impact actions.

## Crypto Oracle boundary

The oracle is a research, education, simulation, evidence-comparison, and risk-analysis system. AI-generated confidence is not proof. The system must preserve timestamps and sources and distinguish facts, calculations, assumptions, forecasts, opinions, and generated scenarios.

It may not autonomously trade, transfer assets, connect a wallet for signing, deploy a smart contract, guarantee returns, or issue personalized financial instructions. Those actions require separate security review and explicit human authorization.

## AI-DNF

AI-DNF uses the same provider-neutral handoff and publishing system. Its full meaning, scope, and repository can be attached later without changing the integration contract.

## Adding future projects

Add one record to `config/project-registry.json`. Gemini, Claude, OpenAI, NotebookLM, Hermes, and future providers can then submit the same handoff format without rebuilding the Control Tower.
