# AI Handoff Template

Use this template when moving work between ChatGPT, Claude, Hermes Agent, Fable 5, Grok, GitHub, or any future AI Clone Engine platform.

```markdown
# AI Handoff Note

## Source AI
Name the AI or tool that produced the work.

Examples: ChatGPT, Claude, Hermes Agent, Fable 5, Grok, Codex, Gemini, local script, human operator.

## Destination
Where should the output go next?

Examples: GitHub repo, GitHub issue, README, product file, prompt pack, campaign folder, agent registry, RiskGate review, customer-facing page.

## Project / Repository
Name the project, business, repository, or product line.

## What was produced
Short summary of the output.

## Why it matters
Explain the business, creative, technical, educational, funding, affiliate, or AI Clone Engine purpose.

## Files or artifacts to save
List the exact files, snippets, prompts, docs, or assets that should be saved.

## Next action
State the next clear step.

## RiskGate notes
Include copyright, privacy, safety, security, factual accuracy, customer-facing, financial, legal, medical, or reputation risks.

## Source/date notes
Record date, source links, and verification status when relevant.
```

## Operating rule

No AI platform output is finished until the useful part is saved, summarized, or queued in GitHub.
