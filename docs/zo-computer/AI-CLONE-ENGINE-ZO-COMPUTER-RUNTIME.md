## GitHub-to-Zo workflow

Use this workflow when GitHub sends work into lippytmai.zo.computer:

1. Select a GitHub document, issue, prompt, registry entry, or product file.
2. Copy the current version into the matching Zo Computer workspace.
3. Use AI tools to expand, test, combine, prototype, or improve it.
4. Mark the Zo output as `draft`, `prototype`, `ready-for-review`, or `ready-for-github`.
5. Send the stable result back to GitHub as a markdown file, registry update, issue note, or product artifact.

## Zo-to-GitHub workflow

Use this workflow when Zo Computer produces useful work:

1. Identify the project name.
2. Identify the source workspace.
3. Summarize what was produced.
4. Convert the output into a GitHub-friendly artifact.
5. Save it to the correct folder in the Control Tower or project repo.
6. Add a handoff note with source, date, purpose, next action, and RiskGate notes.
