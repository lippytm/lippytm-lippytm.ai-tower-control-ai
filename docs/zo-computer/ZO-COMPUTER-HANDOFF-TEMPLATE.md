# Zo Computer Handoff Template

Use this template whenever work is created, changed, tested, or staged inside **lippytmai.zo.computer** and needs to be saved back into GitHub.

```markdown
# Zo Computer Handoff Note

## Source workspace
lippytmai.zo.computer / folder or board name

## Destination GitHub repo
Repository name

## Destination folder or file
Path where this should be saved

## Project
Project, business, product, agent, campaign, or system name

## What was created or changed
Short summary of the useful output

## Status
idea / rough-draft / draft / prototype / testing / ready-for-review / riskgate-review / ready-for-github / committed-to-github / customer-facing-ready / paused / archived

## Business purpose
How this helps lippytm.AI, the AI Clone Engine, AgentBots, AI Swarms, publishing, affiliate systems, business funding, customer/client workflows, or revenue generation

## Files or artifacts to save
List docs, prompts, screenshots, dashboards, exports, scripts, campaign assets, product drafts, registries, or issue notes

## Next action
The next clear action to take

## RiskGate notes
Security, privacy, copyright, factual accuracy, financial/legal/medical, customer-facing, or reputation concerns

## Source/date notes
Date, source platform, related AI tool, and verification status
```

## Operating rule

Zo Computer is the flexible workspace. GitHub is the durable record. Useful Zo Computer work should not stay isolated; it should be saved, summarized, or queued in GitHub.
