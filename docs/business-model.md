# Business Model

The lippytm.ai Control Tower operates as the command center for the Business-of-Businesses (BoB) AI Coding and Automation Network.

## Model overview

The BoB network generates value by connecting AI coding, automation, platform integration, agent development, and support into a unified, self-improving system. The Control Tower coordinates the fleet and routes value across lanes.

## Revenue lanes

| Lane | Description | Monetization path |
|---|---|---|
| **AI Coding Services** | Custom AI coding, agent builds, automation pipelines | Retainer, project, affiliate |
| **Business Funding** | Lead capture and referral via lippytmai.getbizfunds.com | Referral fees, affiliate commissions |
| **Education** | Earn While You Learn curriculum and coaching | Course sales, subscriptions |
| **SaaS / API** | Control Tower API, bot hosting, swarm services | Monthly subscriptions |
| **Creative Licensing** | CryptoSteampunk, AI-Time-Machines IP | Licensing, NFT, media |
| **Consulting** | Repo modernization, AI readiness audits | Hourly, retainer |
| **Affiliate** | Tool and platform affiliate links | Commission |

## Operating loop

```
Idea → GitHub issue → Zapier workflow → Dubb video follow-up → Revenue path → Safety gate → Next build step
```

## Monetization priorities

1. **Near-term (0–90 days):** Affiliate commissions, consulting, small project retainers
2. **Mid-term (3–6 months):** SaaS subscriptions, course sales, bot-hosting packages
3. **Long-term (6–18 months):** Platform licensing, creative IP, fleet-as-a-service
