# Prompt #11: Evolutionary Evolutions Control Tower

Prompt #11 is the operating layer for the lippytm.AI Life / Business of Businesses / Systems of Systems portfolio.

It turns ideas, code requests, business tasks, documentation tasks, AI swarm tasks, and development opportunities into structured GitHub work that can be planned, implemented, reviewed, approved, and improved.

## Core Operating Law

```text
AI proposes -> RiskGate evaluates -> human owner approves -> agents execute -> QA verifies -> documentation updates -> systems evolve.
```

## Purpose

Prompt #11 connects:

- GitHub as the durable source of truth.
- Slack as the command and coordination layer.
- ChatGPT as the architecture, planning, documentation, and review layer.
- Claude Code as the scoped implementation layer.
- GitHub Actions as the QA, reporting, routing, and fleet pulse layer.
- RiskGate as the approval and protection layer.

## What Prompt #11 Does

Prompt #11 should help the Control Tower:

1. Capture ideas before they are lost.
2. Convert ideas into GitHub issues.
3. Classify tasks by lane, type, risk, revenue value, and status.
4. Route planning work to ChatGPT.
5. Route implementation work to Claude Code.
6. Track work in GitHub issues and pull requests.
7. Run QA before merge.
8. Require human approval for meaningful changes.
9. Update dashboards and documentation.
10. Feed results back into the next improvement loop.

## Permanent Doctrine

```text
Every idea becomes a task.
Every task becomes documentation.
Every document becomes a system.
Every system becomes a workflow.
Every workflow produces data.
Every data point improves the swarm.
Every swarm improves the business.
Every business improvement funds the next evolution.
```

## MVP Goal

The first Prompt #11 MVP is working when a Slack or ChatGPT idea can become a GitHub issue, receive labels and acceptance criteria, be routed to ChatGPT or Claude Code, move through QA and RiskGate, and update the Control Tower dashboard.
