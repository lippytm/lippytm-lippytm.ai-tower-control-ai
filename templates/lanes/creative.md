# Creative Lane Checklist

Apply this after the universal repo templates. For: `CryptoSteampunk`, `AI-Time-Machines`.

## Foundation checklist

- [ ] `CANON.md` written as first asset — defines world-building rules, tone, characters, and universe
- [ ] Creative direction, tone, and rules documented before any output is generated
- [ ] Creative assets (stories, art, prompts) separated from automation code in subfolders
- [ ] Monetization path identified: licensing, NFTs, media partnerships, affiliate content

## CANON.md template (copy to `CANON.md`)

```markdown
# [Universe Name] Canon

## Universe concept

[One paragraph describing the creative universe.]

## Tone and style

[Describe voice, aesthetic, mood.]

## Core characters or entities

| Name | Role | Description |
|---|---|---|
| [Name] | [Role] | [Description] |

## World rules

- [Rule 1]
- [Rule 2]

## What is out of bounds

- [Excluded themes or directions]

## Monetization path

- [Licensing / NFT / media / affiliate / other]
```

## Monetization checklist

- [ ] Licensing or IP ownership documented
- [ ] NFT or digital asset plan reviewed for compliance
- [ ] Affiliate content labeled correctly
- [ ] No unsupported financial return claims on creative IP

## Security checklist

- [ ] No real credentials in creative content
- [ ] AI-generated content labeled as such when required by law or platform policy
- [ ] Human review before commercial publication
