# Strategy Lane Checklist

Apply this after the universal repo templates. For: `quantum-leap`, `civilization-blueprint`.

## Foundation checklist

- [ ] README has a one-page executive summary before any detail
- [ ] Roadmap uses three time horizons: near-term (90 days), mid-term (6 months), long-horizon (1–3 years)
- [ ] Every strategy doc has a concrete next action and an owner
- [ ] Review date added to the top of each file: `Last reviewed: YYYY-MM-DD`
- [ ] Quarterly review cadence established

## Executive summary template (add to top of README)

```markdown
## Executive Summary

**Vision:** [One sentence — the long-horizon goal.]

**Mission:** [One sentence — what this repo does today to move toward the vision.]

**Near-term (90 days):** [Top 3 priorities]

**Mid-term (6 months):** [Top 3 goals]

**Long-horizon (1–3 years):** [Strategic objectives]

**Owner:** [Name or role]
**Last reviewed:** YYYY-MM-DD
```

## Three-horizon roadmap template

```markdown
## Near-term (90 days)
- [ ] [Action with owner]

## Mid-term (6 months)
- [ ] [Goal with success metric]

## Long-horizon (1–3 years)
- [ ] [Strategic objective]
```

## Compliance checklist

- [ ] No unsupported outcome guarantees in strategy docs
- [ ] Financial projections marked as estimates, not guarantees
- [ ] Human review before publishing strategy as customer-facing claims
