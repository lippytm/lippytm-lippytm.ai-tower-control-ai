# Language CRM Paths

This file connects programming-language learning to CRM follow-up and GitHub practice.

## Purpose

Use CRM to track what a learner wants to learn, what repo they are practicing in, what task they are working on, and what support they need next.

## Path Groups

| Path | Examples | First Task |
|---|---|---|
| Web Builder | HTML, CSS, JavaScript, TypeScript | Build a simple page outline |
| Automation Builder | Python, Bash | Write a simple workflow note |
| Data Builder | SQL, Python, R | Define a small data question |
| Systems Builder | C, C++, Rust, Go | Explain a simple program structure |
| App Builder | Java, C#, PHP, Ruby | Map a small app idea |
| Mobile Builder | Swift, Kotlin | Outline a mobile app concept |
| Docs and Config Builder | Markdown, YAML, JSON | Improve a README or checklist |

## CRM Fields

- learner goal
- current level
- language path
- related repo
- current task
- support question
- next action

## Best Practice

Each learner should have one language path, one practice task, one support record, and one next action.
