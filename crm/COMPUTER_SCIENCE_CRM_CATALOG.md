# Computer Science CRM Catalog

This catalog connects computer science classes and categories to the Prompt #11 CRM system.

## Purpose

The CRM should help learners, customers, collaborators, and builders move through computer science topics with clear paths, practice tasks, progress tracking, support, and next actions.

## CRM Learning Law

```text
Interest -> Topic -> Skill Level -> Practice Task -> Review -> Progress -> Next Topic.
```

## Computer Science Categories

| Category | Learner Outcome | CRM Next Action |
|---|---|---|
| Computer Literacy | Understand files, folders, browsers, accounts, and basic tools | Assign beginner setup path |
| Command Line Basics | Navigate a terminal and understand simple commands | Assign shell practice path |
| Git and GitHub | Track work, create issues, write README files, and open pull requests | Assign GitHub practice path |
| Programming Foundations | Understand variables, functions, loops, data, and debugging | Assign first coding task |
| Web Development | Understand pages, styles, scripts, APIs, and app structure | Assign web project path |
| Databases | Understand records, tables, queries, and data modeling | Assign data practice path |
| Data and Analytics | Understand analysis, reporting, charts, and metrics | Assign analytics path |
| AI Tools | Use AI for planning, documentation, review, and learning support | Assign AI tools path |
| Automation | Turn repeated steps into documented workflows | Assign workflow design path |
| Software Engineering | Understand requirements, tests, review, docs, and maintenance | Assign repo project path |
| Cybersecurity Basics | Understand safe accounts, secrets, permissions, and review habits | Assign safety checklist path |
| Cloud and DevOps | Understand hosting, builds, checks, logs, and deployments conceptually | Assign platform review path |
| Blockchain Foundations | Understand blockchain concepts with education-first sandbox practice | Assign blockchain foundations path |
| Product Building | Turn code and docs into products, services, and platforms | Assign product brief path |

## Best Practices

1. Start from the learner goal.
2. Assign one category at a time.
3. Give one small task.
4. Review the result.
5. Record blockers and questions.
6. Turn repeated questions into lessons.
7. Connect lessons to repos, products, services, or platforms.
8. Always provide a next action.

## Principle

A computer science CRM turns broad technical learning into visible progress, support records, portfolio artifacts, and opportunity paths.
