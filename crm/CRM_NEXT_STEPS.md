# CRM Next Steps

This file defines the next small steps for expanding CRM across Prompt #11, the repo fleet, training paths, and product/service systems.

## Immediate Goal

Use the Control Tower as the CRM source of truth before applying CRM files repo by repo.

## Next Steps

1. Keep CRM templates in the Control Tower.
2. Choose one target repo.
3. Add CRM profile files to that repo.
4. Review the repo audience and support path.
5. Connect the repo to products, services, or training paths.
6. Record the next action.
7. Repeat with the next repo.

## First Repo Target

Start with Web3AI.

Reason:

- Web3 learning
- blockchain education
- GitHub practice
- AI tools
- product/service potential

## CRM Rollout Files

Each target repo should eventually receive:

- CRM_PROFILE.md
- CUSTOMER_OR_LEARNER_PATH.md
- SUPPORT_AND_FOLLOW_UP.md
- PRODUCT_SERVICE_LINKS.md
- PROMPT_11_CRM_NODE.md

## Repo Review Questions

- Who does this repo help?
- What path does it support?
- What questions may people ask?
- What product or service does it connect to?
- What training path does it support?
- What is the next action?

## Principle

CRM should make every repo better at remembering people, paths, support needs, offers, and next actions.
