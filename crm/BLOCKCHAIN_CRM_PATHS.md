# Blockchain CRM Paths

This file connects blockchain learning paths to CRM follow-up, GitHub practice, and sandbox-first project development.

## Purpose

Use CRM to guide learners through blockchain concepts, Web3 project ideas, documentation habits, and safe practice paths.

## Education Boundary

Blockchain CRM paths should be education-first, sandbox-first, and documentation-first unless a separate review approves a different use.

## Path Groups

| Path | Focus | First Task |
|---|---|---|
| Blockchain Literacy | vocabulary, networks, wallets, ledgers | Define key terms |
| Web3 Project Basics | apps, users, interfaces, wallets conceptually | Outline a simple Web3 app idea |
| Smart Contract Concepts | purpose, risks, review mindset | Explain a contract use case |
| Blockchain Security Mindset | careful review, assumptions, limits | Write a safety checklist |
| GitHub Web3 Portfolio | docs, issues, small commits, examples | Create a project README |
| Blockchain Analytics | data questions, dashboards, reports | Define one analytics question |

## CRM Fields

- learner goal
- current level
- blockchain path
- related repo
- sandbox project idea
- current task
- support question
- next action

## Best Practice

Each blockchain learner should have a clear learning goal, a sandbox practice path, review notes, and a next action.
