# Training Path Catalog

This catalog organizes teaching and training paths for programming, blockchain development, GitHub, AI tools, and automation.

## Programming Foundations

Audience:

- beginners
- career changers
- business owners who want technical literacy

Outcomes:

- understand files and folders
- use basic command line concepts
- understand GitHub basics
- read simple code
- write simple scripts or pages
- document learning progress

Starter tasks:

- create a learner profile
- write a README
- edit markdown
- explain variables and functions
- build a tiny HTML page

## GitHub Practice Path

Audience:

- learners building proof-of-work
- junior developers
- AI-assisted builders

Outcomes:

- create issues
- make small commits
- open pull requests
- write README files
- understand review cycles
- build a project portfolio

Starter tasks:

- create first issue
- update README
- create a checklist
- document a project idea

## Web Development Path

Audience:

- builders who want websites, apps, and dashboards

Outcomes:

- understand frontend and backend basics
- connect pages to data
- understand APIs
- build simple interfaces
- document deployment notes

Starter tasks:

- create landing page outline
- define user journey
- map page sections
- review app structure

## AI Tools and Automation Path

Audience:

- business owners
- operators
- creators
- developers using AI tools

Outcomes:

- use AI for planning
- create useful prompts
- turn chat into GitHub issues
- build checklists
- design automation flows
- document processes

Starter tasks:

- write one prompt pack
- create one workflow brief
- document one business process
- create one QA checklist

## Blockchain Foundations Path

Audience:

- learners exploring blockchain development
- Web3 builders
- business owners seeking blockchain literacy

Outcomes:

- understand wallets and networks conceptually
- understand smart contract purpose
- use sandbox-first learning
- read contract examples carefully
- understand security review mindset
- document risk and limitations

Starter tasks:

- define blockchain terms
- compare networks at a high level
- outline a sandbox project
- write a security-minded checklist

## Business Automation Builder Path

Audience:

- business owners
- automation builders
- CRM operators
- bot builders

Outcomes:

- define a lead pipeline
- build a customer journey
- design chatbot flow
- connect CRM stages
- document service delivery

Starter tasks:

- create customer intake checklist
- define lead stages
- write follow-up message templates
- map service delivery steps

## Principle

Training paths should produce visible progress, useful artifacts, and the next clear learning step.
