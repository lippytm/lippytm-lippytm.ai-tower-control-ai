# Learner Pipeline

This pipeline helps track people learning programming, blockchain development, AI tools, GitHub, and automation.

## Pipeline Flow

```text
Interest -> Intake -> Skill Check -> Path Assigned -> First Task -> Review -> Progress -> Next Offer.
```

## Stage 1: Interest

The learner shows interest through:

- social post
- landing page
- chatbot
- referral
- email
- direct message
- community conversation

## Stage 2: Intake

Collect:

- name
- contact path
- goal
- current skill level
- preferred learning area
- time available
- first problem they want to solve

## Stage 3: Skill Check

Classify:

- beginner
- early intermediate
- intermediate
- advanced
- unknown

## Stage 4: Path Assigned

Assign one path:

- Programming Foundations
- GitHub Practice
- Web Development
- AI Tools and Automation
- Blockchain Foundations
- Business Automation Builder
- Mixed Custom Path

## Stage 5: First Task

Give a small task:

- create GitHub account
- create README
- edit a markdown file
- complete a coding exercise
- explain a concept
- build a tiny webpage
- review a sample smart contract concept in sandbox notes

## Stage 6: Review

Review:

- completion
- clarity
- questions
- blockers
- next lesson

## Stage 7: Progress

Track:

- completed tasks
- skill confidence
- project artifacts
- GitHub proof-of-work
- support needs

## Stage 8: Next Offer

Offer one clear next step:

- free lesson
- starter prompt pack
- launch map
- coaching call
- setup service
- membership
- project review

## Principle

A learner should always know where they are, what they are learning, what they finished, and what to do next.
