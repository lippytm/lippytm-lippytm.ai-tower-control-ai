## Review Questions

1. What does this system do?
2. Who is it for?
3. What repo or document stores its durable record?
4. What work should happen first?
5. What should be reviewed before expansion?
6. What documentation is missing?
7. What quality check is needed?
8. What is the next useful step?

## Output

After review, produce one of:

- issue
- document
- checklist
- product brief
- service brief
- repo profile
- dashboard update
- next action note

## Principle

A Prompt #11 Engine should make work clearer, smaller, better documented, and easier to improve.
