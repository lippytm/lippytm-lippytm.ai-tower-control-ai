# CRM Repo Checklist

Use this checklist when adding CRM to a repository.

## Required Files

- [ ] CRM_PROFILE.md
- [ ] CRM_NODE.md
- [ ] CUSTOMER_OR_LEARNER_PATH.md
- [ ] SUPPORT_AND_FOLLOW_UP.md
- [ ] PRODUCT_SERVICE_LINKS.md

## Review Questions

- [ ] Who does this repo help?
- [ ] What path does this repo support?
- [ ] What product or service is connected?
- [ ] What support questions may appear?
- [ ] What learning path is connected?
- [ ] What is the next action?

## CRM Status

- missing
- planned
- partial
- active
- blocked

## Rollout Rule

Add CRM to one repo at a time and review before cloning the pattern to the next repo.

## Principle

CRM should make repo relationships, support needs, offers, and next actions easier to see.
