# Support and Follow-Up

This file defines how support questions, learner blockers, customer needs, and follow-up actions are handled for this repository.

## Support Types

- learner question
- customer question
- setup help
- bug or issue report
- documentation question
- product question
- service question
- collaboration question

## Follow-Up Record

| Field | Notes |
|---|---|
| Person or group | Who needs follow-up? |
| Topic | What is the question or need? |
| Related repo | Which repo is involved? |
| Related product or service | What offer is connected? |
| Status | new, active, waiting, resolved, parked |
| Next action | What should happen next? |

## Follow-Up Flow

```text
Question -> Classify -> Answer or route -> Record next action -> Follow up -> Improve docs
```

## Best Practice

When the same question appears more than once, turn it into:

- FAQ entry
- lesson
- checklist
- support script
- product improvement
- service improvement
